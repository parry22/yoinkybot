## Pre-publish checklist

**Substance**
- [ ] Can I say in one sentence what this contains that nothing else does?
- [ ] Every claim has a number, source, or firsthand example
- [ ] Nothing I'd have to fudge to defend

**Structure**
- [ ] Answer-first block in the first 60 words
- [ ] One H1; H2 every 250–400 words; most H2s phrased as questions
- [ ] Paragraphs 2–4 sentences
- [ ] At least one table or structured block
- [ ] Every section makes sense out of context

**SEO**
- [ ] Keyword in title tag, H1, first 100 words, one subhead — density under 2.5%
- [ ] Title ≤60 chars, meta ≈155
- [ ] Descriptive slug
- [ ] 2+ internal links out (pillar + sibling), planned internal links in
- [ ] 3+ external links to primary sources
- [ ] Alt text on every image
- [ ] Schema added

**GEO**
- [ ] 4+ sourced statistics per 1,000 words
- [ ] At least one direct quotation from a named source
- [ ] Named author with real bio; visible publish/update date
- [ ] First-person experience present
- [ ] Not blocked to AI crawlers in robots.txt

**Craft**
- [ ] Cut the first two paragraphs and checked whether it improved
- [ ] Read aloud; fixed every stumble
- [ ] Generic-writing pass done (see references/craft.md)
- [ ] Ran `python scripts/content_audit.py draft.md --keyword "..."`

**Distribution**
- [ ] Email list
- [ ] 5–10 native social posts drafted
- [ ] Communities identified
- [ ] Syndication queued with canonical pointing home
- [ ] Everyone cited has been told
- [ ] Internal links added from existing pages
