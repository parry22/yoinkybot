## Internal link graph

The links are the mechanism, not decoration. Missing links is the most common way clusters fail.

```
                    PILLAR
       ┌──────┬───────┼───────┬──────┐
       ▼      ▼       ▼       ▼      ▼
     C1 ←──→ C2      C3 ←──→ C4     C5
```

**Rules:**
- [ ] Every cluster page links UP to the pillar, with anchor text containing the pillar's target term
- [ ] The pillar links DOWN to every cluster page
- [ ] Related cluster pages link SIDEWAYS to each other
- [ ] No orphan pages — every page has at least two inbound internal links
- [ ] Anchor text is descriptive, never "click here" or "read more"
