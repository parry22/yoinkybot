# Contributing to Yoinky

Thanks for helping make Yoinky better.

## Before you start

- Search existing issues before opening a new one.
- Keep pull requests focused on one problem.
- Never commit API keys, database URLs, user data, or `.env` files.
- For a large feature, open an issue first so the approach can be discussed.

## Local development

Follow the self-hosting quick start in [README.md](README.md). Before opening a pull request, run:

```bash
pnpm verify
pnpm build
```

## Pull requests

Explain what changed, why it changed, and how you verified it. Add or update tests when behavior changes. UI changes should include a screenshot or short recording.
